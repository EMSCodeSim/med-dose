# MyMedDose transactional email

MyMedDose uses Resend for application-generated administrator email.

## Required production environment variables

Configure these in Netlify for production/runtime only. Never commit their values.

- `RESEND_API_KEY` — Resend API key with send permission.
- `MYMEDDOSE_EMAIL_FROM` — verified sender, for example `MyMedDose <admin@mymeddose.com>`.

The Netlify function `/.netlify/functions/send-admin-email` supports administrator invitations and password-reset notices.

## Authentication password reset

The actual password reset token/code must continue to be generated by Neon Auth / Better Auth. Resend must be configured as the outbound mail provider for Neon Auth (or Neon Auth must invoke a server-side mail handler) so reset credentials are never generated by the browser or the Netlify function.

Do not put reset tokens, passwords, Neon secrets, or the Resend API key in Vite (`VITE_*`) variables or client-side code.

## Domain verification

Verify the sending domain in Resend and publish the DNS records Resend supplies. Use a dedicated sender such as `admin@mymeddose.com` or `no-reply@mymeddose.com`.

## Validation

After configuration:

1. Send an administrator invitation to a test address.
2. Use Forgot password from `/admin` and confirm the Neon Auth reset code/link arrives.
3. Complete the reset and sign in with the new password.
4. Confirm `admin_audit_log` records the invitation/reset request without storing tokens or passwords.
